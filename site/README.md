# Сайт ShadowRocket

[Открыть сайт](https://simonerrror.github.io/ShadowRocket/).

Главный адрес сайта — `https://simonerrror.github.io/ShadowRocket/`.
На главной и в генераторе сверху находится одинаковое меню:
«Главная», «Shadowrocket», «Clash», «INCY». На главной ссылки ведут к разделам
этой страницы; генератор открывается кнопкой «Собрать локальный конфиг» в разделе
Clash. В генераторе ссылка Clash возвращает к началу формы без сброса полей,
остальные ссылки ведут на главную. Переходы к разделам оставляют отступ сверху.
В автономной HTML-копии ссылки на другие разделы ведут на публичный сайт
только по нажатию; введённые значения в адреса не подставляются.

`site/index.html` — исходник страницы с тремя разделами в едином оформлении:
Shadowrocket, Clash / Mihomo и INCY. Основные действия видны сразу. Каталог
модулей Shadowrocket, инструкции, подписка и проверка подключения раскрываются
по нажатию. Это сокращает прокрутку до остальных клиентов. Tailscale Direct
и Tailscale Tailnet не входят в каталог сайта и таблицу кнопок установки.
Номера и названия модулей совпадают с `#!name` и
[общей таблицей](../docs/shadowrocket-modules.md#порядок-модулей).
DNS Override Example открывает текст для локальной копии без URL обновления.

Кнопки Shadowrocket используют `shadowrocket://`, кнопки INCY — `incy://`.
Переадресация через внешний сервер не требуется. Если браузер мессенджера
не открывает приложение, откройте сайт в Safari.

После изменения страницы или профилей INCY выполните:

```sh
python3 scripts/build_site.py
python3 scripts/build_clash_page.py
python3 scripts/build_awg_page.py
node --test site/awg/test/*.test.mjs
npm test --prefix site/clash
python3 -m unittest discover -s tests
```

Сборка проверяет INCY deeplink и создаёт `docs/index.html`.
Не редактируйте generated-страницу вручную. Изображения и favicon находятся
в `docs/images/` и `docs/favicon.svg`; пути в HTML относительные.

В настройках Pages выберите `Deploy from a branch`, ветку `main`, каталог `/docs`.
Обычный push публикуется штатным механизмом Pages; `deploy-pages.yml`
проверяет сборку и не дублирует публикацию. Он запрашивает пересборку только
при ручном запуске или после успешного `Sync rule lists`. Cloudflare для сайта не используется.

## Локальный генератор Clash

`site/clash/` содержит переносимую общую часть существующего генератора
FlClash / Clash Mi. Персональная сборка и приватные сервисы в него не входят.
`docs/clash/index.html` — автономная страница: стили, скрипт, свежий публичный
Clash-шаблон и снимки правил встроены в HTML. В браузере Node/npm не нужны.
Главная и генератор используют одну светлую палитру и одинаковое оформление меню.
Сборка использует те же закреплённые `yaml 2.9.1` и `esbuild 0.28.1`,
которые уже применяются локальным генератором.

Ввод остаётся в памяти вкладки и в скачанном YAML. CSP запрещает сетевые
соединения и отправку форм; хеши встроенного скрипта и стилей пересчитываются
при сборке. Нет внешних скриптов, аналитики и постоянного хранилища.
Кнопка офлайн-загрузки сохраняет HTML без введённых данных.
Подробности и границы защиты описаны в [инструкции Clash](../docs/clash-verge-rev.md).

## Локальный конвертер AWG

[Открыть конвертер](https://simonerrror.github.io/ShadowRocket/awg/).
Кнопка «AWG .conf → ссылка» находится в разделе Shadowrocket на главной.
Страница принимает один UTF-8 `.conf` размером до 64 КиБ и создаёт ссылку
`wg://` для импорта из буфера обмена Shadowrocket. Ссылку можно скопировать
или скачать в TXT. Кнопка «Открыть в Shadowrocket» передаёт готовый узел
установленному приложению через `shadowrocket://add/{url}` без посредника.
Схема описана в [руководстве Shadowrocket](https://github.com/LOWERTOP/Shadowrocket/wiki#url-schemes).
Если браузер мессенджера блокирует переход, откройте страницу в Safari.
Файл содержит одну секцию Interface и одну Peer.

Браузерная реализация воспроизводит формат действующего локального конвертера:
AWG1, полный набор AWG2 и дополнительные поля AWG3/3.1, включая нормализацию
RandomTrailers и DisableCookies. Неизвестные поля, частичный AWG2, несколько
пиров и маршруты AllowedIPs, отличные от полного туннеля IPv4 или IPv4+IPv6,
отклоняются без частичного результата. DNS, PresharedKey и PersistentKeepalive
можно пропустить; присутствующие значения проверяются и переносятся в ссылку.

Файл и ссылка остаются в памяти вкладки. Страница не отправляет их на сервер,
не записывает в адрес, журналы или постоянное хранилище. CSP запрещает сетевые
запросы и отправку форм. Аналитики и внешних ресурсов нет. GitHub Pages
обслуживает только статический HTML. Копирование и скачивание выполняются
только по нажатию. «Очистить» удаляет результат и выбор файла.

Кнопка «Скачать офлайн-конвертер» сохраняет исходную HTML-страницу без
выбранного файла, результата и сообщений. Откройте эту копию без сети.
Ссылка содержит приватный ключ: передавайте её только своему VPN-клиенту.

Исходники находятся в `site/awg/`. Сборка встраивает JavaScript и общие стили
генератора Clash, затем вычисляет хеши CSP. Новых зависимостей нет.
Документация и проверки подтверждают формат ссылки; подключение зависит от
профиля, сервера и поддержки полей установленной версией Shadowrocket.

```sh
python3 scripts/build_awg_page.py
node --test site/awg/test/*.test.mjs
```

`docs/awg/index.html` — generated-файл; не редактируйте его вручную.
