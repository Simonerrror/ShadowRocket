# Сайт ShadowRocket

[Открыть сайт](https://simonerrror.github.io/ShadowRocket/).

Главный адрес сайта — `https://simonerrror.github.io/ShadowRocket/`.
На главной и в генераторе сверху находится одинаковое меню:
«Главная», «Shadowrocket», «Clash», «INCY». На главной ссылки ведут к разделам
этой страницы; генератор открывается кнопкой «Собрать локальный конфиг» в разделе
Clash. В генераторе ссылка Clash возвращает к началу формы без сброса полей,
остальные ссылки ведут на главную. Переходы к разделам оставляют отступ сверху.
В автономной HTML-копии ссылки на другие разделы ведут на публичный сайт
только по нажатию; введённые значения в адреса не подставляются.

`site/index.html` — исходник страницы с тремя разделами в едином оформлении:
Shadowrocket, Clash / Mihomo и INCY. Основные действия видны сразу. Каталог
модулей Shadowrocket, инструкции, подписка и проверка подключения раскрываются
по нажатию. Это сокращает прокрутку до остальных клиентов. Tailscale Direct
и Tailscale Tailnet не входят в каталог сайта и таблицу кнопок установки.
Номера и названия модулей совпадают с `#!name` и
[общей таблицей](../docs/shadowrocket-modules.md#порядок-модулей).
DNS Override Example открывает текст для локальной копии без URL обновления.

Кнопки Shadowrocket используют `shadowrocket://`, кнопки INCY — `incy://`.
Переадресация через внешний сервер не требуется. Если браузер мессенджера
не открывает приложение, откройте сайт в Safari.

После изменения страницы или профилей INCY выполните:

```sh
python3 scripts/build_site.py
python3 scripts/build_clash_page.py
python3 scripts/build_awg_page.py
node --test site/awg/test/*.test.mjs
npm test --prefix site/clash
python3 -m unittest discover -s tests
```

Сборка проверяет INCY deeplink и создаёт `docs/index.html`.
Не редактируйте generated-страницу вручную. Изображения и favicon находятся
в `docs/images/` и `docs/favicon.svg`; пути в HTML относительные.

В настройках Pages выберите `Deploy from a branch`, ветку `main`, каталог `/docs`.
Обычный push публикуется штатным механизмом Pages; `deploy-pages.yml`
проверяет сборку и не дублирует публикацию. Он запрашивает пересборку только
при ручном запуске или после успешного `Sync rule lists`. Cloudflare для сайта не используется.

## Локальный генератор Clash

`site/clash/` содержит переносимую общую часть существующего генератора
FlClash / Clash Mi. Персональная сборка и приватные сервисы в него не входят.
`docs/clash/index.html` — автономная страница: стили, скрипт, свежий публичный
Clash-шаблон и снимки правил встроены в HTML. В браузере Node/npm не нужны.
Главная и генератор используют одну светлую палитру и одинаковое оформление меню.
Сборка использует те же закреплённые `yaml 2.9.1` и `esbuild 0.28.1`,
которые уже применяются локальным генератором.

Ввод остаётся в памяти вкладки и в скачанном YAML. CSP запрещает сетевые
соединения и отправку форм; хеши встроенного скрипта и стилей пересчитываются
при сборке. Нет внешних скриптов, аналитики и постоянного хранилища.
Кнопка офлайн-загрузки сохраняет HTML без введённых данных.
Подробности и границы защиты описаны в [инструкции Clash](../docs/clash-verge-rev.md).

## Локальный конвертер AWG / TrustTunnel

[Открыть конвертер](https://simonerrror.github.io/ShadowRocket/awg/).
Кнопка «AWG / TrustTunnel → Shadowrocket» находится в разделе Shadowrocket на главной.
Страница принимает несколько `.conf`, `.vpn` и ZIP с этими файлами.
В поле «Текст .vpn или конфиг Mihomo» можно вставить содержимое одного
текстового `.vpn`, ссылку `vpn://`, JSON Amnezia или YAML/JSON Mihomo размером до 2 МиБ.
Поле работает без выбранных файлов или вместе с ними: все входы образуют
один набор с общей кнопкой импорта в SR. Вставленный текст учитывается как
один дополнительный файл. Изменение текста удаляет устаревший результат;
«Очистить» удаляет текст, выбор файлов и готовые ссылки. Офлайн-копия
сохраняется без вставленного текста.
Можно передать до 100 входов; результат содержит до 100 AWG-профилей.
Ограничения: `.conf` — 64 КиБ, `.vpn` — 2 МиБ, ZIP — 8 МиБ,
весь выбранный и распакованный набор — 16 МиБ. ZIP поддерживает методы
stored/deflate без пароля; вложенные архивы и неизвестные файлы отклоняются.
Служебные файлы macOS пропускаются. Распаковка выполняется в памяти вкладки.

`.vpn` Amnezia принимается как текст `vpn://` с Base64URL и qCompress,
как JSON или бинарный qCompress. Из `containers[].awg.last_config`
извлекается готовый `config` с AWG. Сжатие и структура сверены с
[исходниками Amnezia](https://github.com/amnezia-vpn/amnezia-client/blob/ac175c8a8147cfe56f98c8372ec17ea2ba00bb02/client/core/controllers/selfhosted/importController.cpp).
Контейнеры других протоколов не преобразуются. Если готового клиентского AWG
нет, требуется экспорт подключения AWG, а не административного доступа.
Повреждённый профиль останавливает весь набор без частичного результата.
Повтор одного профиля отклоняется; разные профили сохраняют свои имена.

Имена экспортируемых узлов заканчиваются отдельным маркером протокола:
`AWG2` для AmneziaWG 2, `AWG3.1` для AmneziaWG 3.1, `TT` для TrustTunnel;
для Naive используется `NV`. Для прежнего AWG сохраняется `AWG`, для AWG3 — `AWG3`.
Конвертер добавляет нужный суффикс, заменяет старый маркер другого протокола
и удаляет повторы. Например: `Germany AWG3.1 AWG` → `Germany AWG3.1`,
`Germany TT TT` → `Germany TT`. Версия AWG определяется по полям профиля,
а не по исходному имени; параметры обфускации сохраняются. Одно и то же имя используется в списке узлов,
в ссылке открытия SR и в одиночном или общем TXT.

Конвертер также принимает `.yaml`, `.yml` и `.json` Mihomo размером до 2 МиБ,
в том числе внутри ZIP. Можно вставить полный конфиг в то же текстовое поле.
Из полного конфига извлекаются только `type: trusttunnel` из `proxies`;
отдельное описание одного TT-узла тоже поддерживается. Другие протоколы,
правила, DNS и группы не переносятся; число пропущенных узлов видно в результате.
Удалённые `proxy-providers` не загружаются. Если TT есть только в провайдере,
сначала скачайте его YAML и добавьте как локальный файл.

TrustTunnel преобразуется в статические TLV-ссылки `tt://?` в формате
действующего TT-конвертера. Сохраняются имя, сервер, порт, SNI, логин, пароль,
проверка сертификата, HTTP/2 или QUIC/HTTP/3 и явный has-ipv6.
`client-fingerprint`, `health-check` и `udp` не имеют соответствующих полей
в TT-ссылке; страница перечисляет их отдельно. Неизвестное или непредставимое
поле выбранного TT-узла останавливает набор, а не пропускается молча.
Сведения о маршрутизации полного конфига не заменяют настройки Shadowrocket.
Формат описан в [TrustTunnel Deep Link](https://github.com/TrustTunnel/TrustTunnel/blob/master/DEEP_LINK.md).

В результате выберите «Весь набор» или один узел. Выбор определяет содержимое
поля ссылок, скачиваемого TXT, копирования и кнопки открытия Shadowrocket.
Для одного выбранного узла используется прямой `shadowrocket://add/{url}`;
весь набор передаётся через локальный буфер обмена, как описано ниже.

Результат — список `wg://` и `tt://?`, по одной ссылке на узел. Его можно скопировать
или скачать одним TXT. Для одного узла «Открыть в Shadowrocket» использует
`shadowrocket://add/{url}`. Для нескольких узлов кнопка «Добавить весь набор
в Shadowrocket» копирует весь список в буфер обмена и открывает приложение
через `shadowrocket://`. SR распознаёт список при разрешённом доступе к буферу;
подтверждение импорта остаётся в приложении. Если автораспознавание выключено,
нажмите «Вставить» в SR. При запрете браузерного копирования список выделяется
для ручного копирования; частичный набор в приложение не передаётся.
Схема описана в [руководстве Shadowrocket](https://github.com/LOWERTOP/Shadowrocket/wiki#url-schemes).
Если браузер мессенджера блокирует переход, откройте страницу в Safari.
Каждый извлечённый `.conf` содержит одну секцию Interface и одну Peer.

Браузерная реализация воспроизводит формат действующего локального конвертера:
AWG1, полный набор AWG2 и дополнительные поля AWG3/3.1, включая нормализацию
RandomTrailers и DisableCookies. Неизвестные поля, частичный AWG2, несколько
пиров и маршруты AllowedIPs, отличные от полного туннеля IPv4 или IPv4+IPv6,
отклоняются без частичного результата. DNS, PresharedKey и PersistentKeepalive
можно пропустить; присутствующие значения проверяются и переносятся в ссылку.

Файлы и ссылки остаются в памяти вкладки до копирования, скачивания или передачи SR.
Страница не отправляет их на сервер,
не записывает в адрес, журналы или постоянное хранилище. CSP запрещает сетевые
запросы и отправку форм. Аналитики и внешних ресурсов нет. GitHub Pages
обслуживает только статический HTML. Копирование и скачивание выполняются
только по нажатию. «Очистить» удаляет результат и выбор файла.

Кнопка «Скачать офлайн-конвертер» сохраняет исходную HTML-страницу без
выбранного файла, результата и сообщений. Откройте эту копию без сети.
Ссылка содержит приватный ключ: передавайте её только своему VPN-клиенту.

Исходники находятся в `site/awg/`. Сборка встраивает JavaScript и общие стили
генератора Clash, его ZIP-распаковщик и закреплённый YAML-парсер; затем вычисляет хеши CSP.
Используются уже закреплённые yaml 2.9.1 и esbuild 0.28.1 из site/clash; новых зависимостей нет.
Документация и проверки подтверждают формат ссылки; подключение зависит от
профиля, сервера и поддержки полей установленной версией Shadowrocket.

```sh
python3 scripts/build_awg_page.py
node --test site/awg/test/*.test.mjs
```

`docs/awg/index.html` — generated-файл; не редактируйте его вручную.
