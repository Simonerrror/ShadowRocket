# Shadowrocket: установка и настройка

Основной профиль — [`shadowrocket.conf`](../shadowrocket.conf). Он задаёт
маршрутизацию и сетевые настройки. Серверы добавляются отдельно из вашей подписки
или вручную. Для Clash используйте [отдельную инструкцию](clash-verge-rev.md).

## Установка

1. Добавьте свою подписку на серверы в Shadowrocket.
2. Откройте [ссылку добавления конфига](https://simonerrror.github.io/ShadowRocket/#shadowrocket)
   на устройстве с установленным Shadowrocket. Если встроенный браузер мессенджера
   не открывает приложение, используйте Safari.
3. Выберите загруженный конфиг в разделе **Config / Конфигурация**.
4. В группе `PROXY` оставьте `AUTO-SPEED` для автоматического выбора узла.

Для ручного добавления откройте **Config → Add Config → URL** и вставьте:

```text
https://raw.githubusercontent.com/Simonerrror/ShadowRocket/main/shadowrocket.conf
```

Конфиг обновляется по `update-url`. После изменения локальной копии проверьте,
сохранились ли ваши настройки при следующем обновлении.

## Выбор серверов

| Группа | Назначение |
| --- | --- |
| `PROXY` | Главный переключатель между `AUTO-SPEED`, `MANUAL-PROXY` и `WL`; по умолчанию выбран `AUTO-SPEED` |
| `AUTO-SPEED` | Автоматический выбор по результатам проверки узлов |
| `MANUAL-PROXY` | Ручной выбор узла без отдельных меток `WL` и `SS` в имени |
| `WL` | Ручной выбор узлов любого протокола с отдельной меткой `WL` в имени |

Фильтр `AUTO-SPEED` принимает узлы без обязательной метки протокола в имени,
включая Hysteria/Hysteria2. Имена с `Russia`, `Belarus`, `Ukraine` или отдельными
метками `WL` и `SS` исключаются. Фильтры работают по именам узлов; строка типа
протокола в интерфейсе в проверке не участвует.

Переименовывать узлы провайдерской подписки для участия в `AUTO-SPEED` не нужно.
Исключение `SS` требует этой отдельной метки в имени: скрытый тип протокола
такой фильтр не распознаёт.

`AUTO-SPEED` использует `url-test` с адресом
`https://www.youtube.com/favicon.ico`, интервалом 180 секунд,
`tolerance=100` и `timeout=7`.

## Дополнительные модули

Модули подключаются отдельно через **Config → Modules → Add** и могут изменять
правила активного конфига. Ссылки и порядок включения находятся в
[инструкции по модулям](shadowrocket-modules.md).

Для Gemini используется Smart DNS: настройте DNS Override Example и добавьте Google AI
Smart DNS по [инструкции DNS](dns-override.md). Персональные адреса DNS задаются
в локальной копии модуля.

## Что находится в конфиге

### `[General]`: сеть и DNS

- Основной DNS: `9.9.9.9`, `149.112.112.112`, `77.88.8.8`.
- Резервный `fallback-dns-server` использует тот же набор.
- DNS для прямых доменных правил: `77.88.8.8`, `77.88.8.1`.
- IPv6 выключен: `ipv6=false`, `prefer-ipv6=false`.
- Локальные адреса и домены перечислены в `skip-proxy` и `bypass-tun`.
- `update-url` указывает на основной конфиг в репозитории.

Модуль DNS Override Example может заменить DNS активного профиля.

### `[Proxy Group]`: группы

В этой секции заданы четыре группы из таблицы выше, фильтры по именам узлов,
адрес проверки и параметры автоматического выбора.

### `[Rule]`: порядок маршрутизации

Правила обрабатываются сверху вниз:

1. `torrent_block` блокирует известные торрент-трекеры и начальные узлы DHT.
2. `whitelist_direct` задаёт ручные исключения для `DIRECT`.
3. `greylist_proxy` задаёт ручные исключения для `PROXY`.
4. `microsoft` направляет Microsoft, Office 365, Teams и OneDrive через `PROXY`
   с модификатором `force-remote-dns`.
5. `domains_community` направляет сервисы общего списка через `PROXY`.
6. Домены `.ru`, `.рф`, `.su` и адреса, совпавшие с `GEOIP,RU`, идут напрямую.
7. Остальной трафик обрабатывается правилом `FINAL,PROXY`.

Модули могут добавлять правила с более высоким приоритетом. Поэтому учитывайте
и порядок правил профиля, и [порядок модулей](shadowrocket-modules.md).

## Настройка собственных исключений

В исходниках проекта ручные изменения списков принадлежат overlays:

- [`whitelist_direct.add.list`](../distillate/overlays/whitelist_direct.add.list) — принудительный `DIRECT`;
- [`greylist_proxy.add.list`](../distillate/overlays/greylist_proxy.add.list) — принудительный `PROXY`.

Через `whitelist_direct` ведутся, в частности, исключения Path of Exile.
В `greylist_proxy` закреплены `googlevideo.com`, а также домены X/Twitter
`t.co`, `x.com`, `twitter.com`, `twimg.com`.
Порядок пересборки описан в [инструкции по сопровождению](maintenance.md).
