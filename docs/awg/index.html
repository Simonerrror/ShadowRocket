Открыть в Shadowrocket ↗

Нажмите «Открыть в Shadowrocket» и подтвердите добавление узла в приложении. Можно также импортировать ссылку из буфера обмена. Ссылка содержит приватный ключ.

↳

Только в браузере

Файл и ключи не передаются на сервер. Нет аккаунта, аналитики и постоянного хранилища. Сетевые запросы страницы запрещены.

GitHub Pages отдаёт статическую страницу. Обработка начинается на вашем устройстве после выбора файла.

Можно без сети

Скачайте чистую HTML-копию. Откройте её без подключения к интернету и преобразуйте свой файл.

Копия не содержит выбранного файла или готовой ссылки.

Формат и исходники

Неизвестные поля, несколько Peer и отдельные маршруты AllowedIPs отклоняются. Для новых полей нужна версия Shadowrocket с их поддержкой.
