# Страница ссылок

`public/index.html` — самостоятельная компактная страница MotivatoPotato.
Сначала кнопка конфига Shadowrocket, затем шесть модулей и два профиля INCY.
Блог и GitHub находятся внизу. Описания скрыты в раскрывающихся блоках.
DNS override стоит первым; номера кнопок задают порядок модулей.
Раздел конфига содержит два скриншота и описание трёх групп и селектора PROXY.
Обычный режим — PROXY → AUTO-SPEED; WL и MANUAL-PROXY выбираются при необходимости.

Страница использует существующие ссылки импорта и прямые ссылки на модули.
Добавлены две реферальные ссылки и пояснение связи подписки со Smart DNS
и фильтрами групп. Личный контакт ещё не задан.
HTML не требует сборки. Текущие маршруты Worker не изменяются.

Кнопка DNS Override использует публичный `modules/dns_override.module` из GitHub.
Адреса задаются вручную после = в dns-server и direct-dns-server.
Smart DNS обязателен для прямого DNS; резервный DNS остаётся из конфига.

Страница ссылок публикуется в корне Worker. `/links` перенаправляет в корень.
Импорт: `/sr/config`, `/sr/modules/<имя>`, `/incy`, `/incy/ru`.
Поддержка HAPP прекращена; `/ru` больше не используется.
