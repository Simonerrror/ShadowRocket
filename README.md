# ShadowRocket

Конфиги маршрутизации, модули и обновляемые списки правил для Shadowrocket
и Clash на ядре Mihomo. Серверы добавляются из ваших подписок.

Генератор Clash работает в браузере и доступен как автономный HTML.
Для ручной настройки [скачайте шаблон](clash_config.yaml) и впишите подписку
в `proxy-providers.Main-Sub.url` — [инструкция](docs/clash-verge-rev.md).
