# ShadowRocket

Конфиги маршрутизации, модули и обновляемые списки правил для Shadowrocket
и Clash на ядре Mihomo. Серверы добавляются из ваших подписок.

Для Clash перед импортом замените `<INSERT_SUBSCRIPTION_URL_HERE>` своей ссылкой
на подписку в `proxy-providers.Main-Sub.url`. Для нескольких подписок добавьте
отдельные провайдеры — [порядок настройки](docs/clash-verge-rev.md).
